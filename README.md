# 大口資金流入・初動スクリーナー

日本株の日足データから「大口の買い集めの痕跡 (初動)」をスコア化して
ランキング表示する自分用Webダッシュボードです。

## 仕組み

100点満点のスコアで評価します:

| 項目 | 配点 | 見ているもの |
|---|---|---|
| ① ステルス蓄積 | 30点 | 価格は横ばいなのにOBVが上昇 (隠れた買い集め) |
| ② 出来高の質 | 25点 | 出来高の静かな増加 + 陽線日の出来高優位 |
| ③ 収縮→放れ | 20点 | ボリンジャーバンド収縮後の上放れ |
| ④ 転換初動 | 25点 | RSI 50上抜け / MACDのGC / 25MA奪還が「起きたばかり」 |

さらに乖離率6%超・RSI 72超の銘柄は「過熱 (初動ではない)」として
スコアを強制減点し、乗り遅れ銘柄を除外します。

## セットアップ

Python 3.10以上で:

```bash
pip install streamlit yfinance pandas numpy plotly xlrd
```

## 起動

```bash
cd shodou
streamlit run app.py
```

ブラウザが自動で開きます (http://localhost:8501)。
「スキャン実行」を押すと tickers.csv の全銘柄をスキャンします。

## 銘柄リストの変更

`tickers.csv` を編集してください (code: 4桁の証券コード, name: 銘柄名)。
東証銘柄はYahoo Financeで「XXXX.T」として取得されます。
数百銘柄に増やしてもOKですが、スキャン時間はその分伸びます。

## 対象市場の切り替え

サイドバーの「対象市場」で選択できます:

- **カスタム (tickers.csv)**: 自分で管理する銘柄リスト
- **東証プライム / スタンダード / グロース / 全市場**: JPX公式の
  上場銘柄一覧を自動取得して市場ごとにスキャン (要インターネット接続)

市場全体は銘柄数が多いため「スキャン上限銘柄数」で調整してください。
※ JPX一覧の読み込みに `xlrd` パッケージが必要です。

## 検索・フィルタ

- **銘柄検索**: リスト上部の検索ボックスにコードまたは銘柄名を入力
- **時価総額フィルタ**: サイドバーで最低時価総額 (億円) を指定
- 結果テーブルに市場区分・時価総額の列を表示

## 画面レイアウト

- **左**: チャート (日足 / 週足 のタブ切り替え)
- **右**: 銘柄リスト — 行をクリックすると左のチャートが切り替わります

週足はパラメータを週足スケール (MA=13週、収縮判定=52週) に自動調整して
計算します。週足を使う場合は取得期間を **2y以上** にしてください。


## 🌐 Webサイトとして公開する (Streamlit Community Cloud・無料)

URLでどこからでもアクセスできるようにする手順:

1. **GitHubアカウントを作成** (無料) → 新しいリポジトリを作成
   (公開したくない場合は Private リポジトリでOK)
2. このフォルダのファイルをすべてリポジトリにアップロード
   (app.py, scoring.py, tickers.csv, requirements.txt)
3. https://share.streamlit.io にアクセスし、GitHubアカウントでログイン
4. 「New app」→ リポジトリを選択 → Main file path に `app.py` を指定 → Deploy
5. 数分で `https://あなたのアプリ名.streamlit.app` のURLが発行されます
   → スマホのブックマークに入れれば毎日どこでもチェック可能

### 注意事項

- 無料プランではURLを知っていれば誰でも見られます。自分だけにしたい
  場合はアプリ設定の Sharing で「Only specific people」に変更してください
- しばらくアクセスがないとアプリはスリープします (開けば数十秒で復帰)
- クラウド上からのYahoo Financeアクセスはレート制限がやや厳しいため、
  スキャン上限は200銘柄程度から試すのがおすすめです

### スマホと同じWi-Fiで見るだけなら (公開不要)

自宅PCで以下を実行し、スマホから `http://PCのIPアドレス:8501` にアクセス:

```bash
streamlit run app.py --server.address 0.0.0.0
```

## 使い方のコツ

- **「監視候補のみ (蓄積+収縮)」表示**: まだ放れていないが蓄積の痕跡が
  ある銘柄。監視リストとして毎日チェック
- **「初動シグナルのみ」表示**: スコアが閾値を超え、かつ過熱していない
  銘柄。エントリー候補
- 個別チャートで「価格横ばい + OBV右肩上がり」の形を目視確認してから
  判断するのがおすすめ

## 注意

- データはYahoo Finance (無料) の日足で、20分遅延・調整済み終値です
- 大口の売買は非公開のため、これはあくまで痕跡からの「推定」です
- 決算・ニュースによる出来高急増も検出されるため、必ず材料を確認して
  ください。投資判断は自己責任でお願いします
